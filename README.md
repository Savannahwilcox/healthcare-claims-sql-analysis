# Medicare Claims Utilization and Payment Analysis

## Project Overview

This project uses PostgreSQL to analyze the CMS Medicare Claims Synthetic Public Use Files. The analysis examines healthcare utilization, submitted charges, Medicare payments, diagnoses, and beneficiary characteristics across inpatient and outpatient claims.

The project was created to demonstrate foundational relational database and SQL skills using a realistic healthcare claims structure. The CMS records are synthetic and do not represent actual Medicare beneficiaries.

## Research Questions

1. What are the most common diagnoses represented in inpatient and outpatient claims?

2. How do submitted charges compare with Medicare payments?

3. What is the average payment-to-charge ratio by claim type?

4. Which beneficiaries have the highest number of claims?

5. What is the average inpatient length of stay?

6. How does utilization vary by beneficiary age, sex, and chronic-condition indicators?

7. How do claim volume and payments change over time?

8. Which providers account for the largest claim volume and Medicare payments?

## Planned Tools

- PostgreSQL

- SQL

- CMS Synthetic Medicare Claims Data

- Tableau or Python

- Git and GitHub
